---
title: add
description: Save a new password to your pm vault under a given name.
---

The `add` command stores a new password in your encrypted vault. You provide a name (label) for the password, then enter the password itself twice to confirm it.

## Syntax

```bash
pm add <name>
```

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `<name>` | string | Yes | A label to identify the password (e.g., `github`, `email`, `prod-db`) |

## Behavior

<Steps>
  <Step title="Authenticate with master password">
    Before anything else, `pm` prompts you to enter your master password to unlock the vault.
  </Step>
  <Step title="Enter the password">
    You are prompted: `Enter password for <name> :`. The input is hidden.
  </Step>
  <Step title="Confirm the password">
    You are prompted: `Confirm Password :`. Enter the same password again.
  </Step>
  <Step title="Result">
    If both entries match, `pm` saves the password and prints `Saved successfully!`. If they do not match, it prints `Passwords did not match!` and nothing is saved.
  </Step>
</Steps>

## Example

```bash
$ pm add github
Enter Master Password: 
Enter password for github : 
Confirm Password : 
Saved successfully!
```

If the two password entries do not match:

```bash
$ pm add github
Enter Master Password: 
Enter password for github : 
Confirm Password : 
Passwords did not match!
```

## Tips

<Tip>
  Use descriptive, consistent names for your passwords. Good names make retrieval easy — for example, `github`, `aws-prod`, `gmail-work`, or `postgres-local`.
</Tip>

<Tip>
  Avoid spaces in names. Use hyphens or underscores instead (e.g., `my-server` rather than `my server`) so the name works cleanly as a CLI argument without quoting.
</Tip>
