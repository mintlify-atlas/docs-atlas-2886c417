`pm` organizes all functionality into subcommands. Every command — without exception — requires you to authenticate with your master password before it runs.

<Note>
  If this is your first time running any `pm` command, you will be prompted to set up a master password. Enter it twice to confirm before continuing.
</Note>

## Command summary

| Command | Syntax | Description |
| --- | --- | --- |
| `add` | `pm add <name>` | Prompts for a password and saves it under `<name>` |
| `get` | `pm get <name>` | Prints the password stored under `<name>` |
| `delete` | `pm delete <name>` | Permanently deletes the password stored under `<name>` |
| `list` | `pm list` | Lists the names of all stored passwords |

## Master password authentication

Every command requires your master password before it executes. This protects your entire vault behind a single secret.

```bash
$ pm list
Enter Master Password: 
--- Saved Passwords ---
• github
• email
-----------------------
```

If you enter the wrong master password, the command will not proceed and your vault data will not be accessible.
