title: Quickstart

This guide walks you through first-time setup, creating a master password, storing a credential, retrieving it, listing all entries, and deleting one.

<Warning>
  Your master password cannot be recovered. If you forget it, your encrypted vault cannot be decrypted and all stored passwords will be permanently inaccessible. Store it somewhere safe.
</Warning>

## Getting started

<Steps>
  <Step title="Set your master password">
    The first time you run any `pm` command, you are prompted to create a master password. This password is hashed with Argon2id and stored locally — it is never transmitted anywhere.

    ```bash
    pm list
    ```

    ```
    No master password found. Setup required.
    Enter New Master Password:
    Confirm Master Password:
    Creating new Master Password...
    No passwords saved yet!
    ```

    Enter your chosen master password when prompted, then confirm it. After this step, every subsequent `pm` command will require this password.
  </Step>

  <Step title="Store your first password">
    Use `pm add <name>` to create a new password entry. The `<name>` is a label you choose to identify the credential.

    ```bash
    pm add github
    ```

    ```
    Enter Master Password:
    Enter password for github :
    Confirm Password :
    Saved successfully!
    ```

    Type your master password, then enter the password you want to store for that entry. The value is encrypted immediately and written to your vault.
  </Step>

  <Step title="Retrieve a password">
    Use `pm get <name>` to decrypt and display a stored password.

    ```bash
    pm get github
    ```

    ```
    Enter Master Password:
    Password for github : s3cr3tP@ssw0rd
    ```

    The password is printed to stdout so you can copy it to your clipboard.
  </Step>

  <Step title="List all stored entries">
    Use `pm list` to see the names of every password you have saved. Passwords themselves are not shown — only their names.

    ```bash
    pm list
    ```

    ```
    Enter Master Password:
    --- Saved Passwords ---
    • github
    -----------------------
    ```
  </Step>

  <Step title="Delete an entry">
    Use `pm delete <name>` to permanently remove a password from your vault.

    ```bash
    pm delete github
    ```

    ```
    Enter Master Password:
    Successfully deleted password for: github
    ```

    The entry is removed from the encrypted store. This action cannot be undone.
  </Step>
</Steps>

## Command reference

| Command | Description |
|---|---|
| `pm add <name>` | Store a new password under the given name |
| `pm get <name>` | Retrieve and display a stored password |
| `pm delete <name>` | Permanently remove a stored password |
| `pm list` | List the names of all stored passwords |
| `pm --help` | Print help and exit |

<Tip>
  Choose short, memorable names for your entries — for example, `github`, `email`, or `work-vpn`. You will type them every time you retrieve a password.
</Tip>
