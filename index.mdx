## Why pm?

`pm` is a minimal, offline password manager written in Rust. Your credentials are stored in an encrypted file on your own machine — no accounts, no sync, no telemetry.

<CardGroup cols={2}>
  <Card title="Privacy first" icon="lock">
    Your passwords never leave your machine. The encrypted vault lives in `~/.my_pass_manager/` and never touches a network.
  </Card>
  <Card title="Modern encryption" icon="key">
    Passwords are encrypted with **XChaCha20-Poly1305** and your master key is derived with **Argon2id** — the same algorithms protecting high-security systems.
  </Card>
  <Card title="Memory safe" icon="microchip">
    Sensitive strings are wiped from RAM immediately after use via the `zeroize` crate — no residual secrets left in memory.
  </Card>
  <Card title="Lightweight" icon="bolt">
    A single statically-linked binary. No runtime dependencies, no daemon, no GUI. Starts in milliseconds.
  </Card>
</CardGroup>

## How it works

<Steps>
  <Step title="Set a master password">
    On first run, `pm` prompts you to create a master password. This password is hashed with Argon2id and stored locally — it is the only key to your vault.
  </Step>
  <Step title="Store credentials">
    Use `pm add <name>` to encrypt and save a password under a memorable name like `github` or `email`.
  </Step>
  <Step title="Retrieve credentials">
    Use `pm get <name>` to decrypt and display a stored password. You are always prompted for your master password first.
  </Step>
</Steps>

<Note>
  Your master password is never stored in plain text. If you forget it, your vault cannot be recovered. Keep it safe.
</Note>

## Quick example

```bash
# First run — set up master password
pm add github

# Later — retrieve it
pm get github

# See all stored names
pm list

# Remove a credential
pm delete github
```
